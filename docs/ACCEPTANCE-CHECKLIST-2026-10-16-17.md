# AI Workbench 0.2.65 验收清单（2026-10-16 ~ 10-17）

安装 `release/AI Workbench_0.2.65_x64-setup.exe` 后，按下面逐项勾选。每项先做步骤，再对照预期。界面以产品中文为准。

装好后窗口标题应为「AI 工作台」。命令菜单用 Ctrl+K 打开。

## 已在 main 上（本包仍应正常）

### 文件导航与空项目（#133 / #134）

- [ ] 打开一个有文件的项目。用命令面板「显示/隐藏导航面板」，或在浏览器新标签页点「文件」（Ctrl+P）。
  - 预期：目录只展开，不打开预览；点文件才出现预览。面包屑可下钻目录。
- [ ] 打开一份 Markdown。
  - 预期：顶栏同一排能在「查看源代码」和「查看预览」之间切换，不另开一条薄壳标签。
- [ ] 这一项不要在已经有项目的窗口里做，也不会改你现有的项目。先完全退出「AI 工作台」。开始菜单的快捷方式不会带上临时数据目录，所以从 PowerShell 启动。若程序路径打不开，在开始菜单里对「AI 工作台」选「打开文件所在的位置」，把最后一行换成那个 `AI Workbench.exe`。

  ```powershell
  $env:APPDATA = Join-Path $env:TEMP "awb-accept-empty"
  New-Item -ItemType Directory -Force $env:APPDATA | Out-Null
  & "$env:LOCALAPPDATA\AI Workbench\AI Workbench.exe"
  ```

  侧栏没有任何项目。不要点「新聊天」，也不要点「+」。这个窗口先留着，供下面「项目列表为空」使用。
  - 预期：主区停在「选择一个项目」，不会自己落到一张空白新聊天。
- [ ] 回到平时已经有项目的「AI 工作台」。选中一个还没有会话的项目。
  - 预期：出现可输入的草稿，侧栏不先插一条空会话。发出第一条消息后，草稿换成真正的会话。
- [ ] 回到刚才那个空数据目录的窗口，不要添加项目，看侧栏。看完后关掉这个窗口。平时的项目仍在原来的数据目录里。
  - 预期：提示「还没有项目。点击上方 + 创建。」

### MCP 设置（#135 / #136 / #145）

- [ ] 打开设置里的「MCP 服务器」。在 Codex 与 Claude 两个标签之间来回切。
  - 预期：列表跟当前标签走，不会把上一个 Agent 的行画到这一个上。未安装的标签有说明，不假装已有服务器。
- [ ] 看已有服务器行。在 Codex 里找一条开着的服务器，再关掉它的开关，然后再打开。到 Claude 看一条已经连上的服务器。接着在 Codex 点「添加服务器」，类型选「流式 HTTP」，名称填 `accept-bad-url`，URL 填 `not-a-url`，点「保存」。若这条被存上了，再把它卸载掉。
  - 预期：没有明确「已连接」时显示「已配置」。关掉开关后显示「已禁用」，短提示是「已禁用」；再打开的短提示是「已启用」。Claude 上已经连上的显示「已连接」。开关跟「启用 / 禁用」走。保存被拒绝时，标题是「无法保存 MCP 服务器」，可以点「查看详情」。成功时的短提示是「已保存」。失败标题跟刚才的操作对得上，不和成功提示用同一句。
- [ ] 点「添加服务器」。在 Codex 上看 STDIO 和「流式 HTTP」。在 Claude 上分别选 STDIO、HTTP、SSE。
  - 预期：表单只出现这个传输方式该有的字段。Codex 的类型是 STDIO 和「流式 HTTP」，没有 SSE。Claude 的类型是 STDIO、HTTP、SSE。Codex 能改启用状态；Claude 能填环境变量和启动参数。
- [ ] 把一段服务器 JSON，以及多行「键=值」，贴进添加表单。
  - 预期：只填当前界面有的字段（名称、命令、环境变量、Headers 等）。不该出现的字段不会被塞进来。某一项不合法时，错误写在该项旁边，而不是整表一句话。
- [ ] 环境变量或请求头的值里故意放一个换行后保存。
  - 预期：该项报错（环境变量值不能换行 / 请求头的值不能换行），服务器不会被存成坏配置。

### 右侧栏（#137 / #140）

- [ ] 先在「打开文件」里点开一个文件，确认预览里有这个文件标签，并在筛选框里输入几个字。再用命令面板打开「显示/隐藏“变更”面板」或「显示/隐藏导航面板」。拖动分隔条，再收起、再打开。
  - 预期：列宽还在。收起后再开，筛选字和已选文件的标签都还在。
- [ ] 在「打开文件」的筛选框输入几个字，切到别的标签再回来，或收起右侧栏再打开。
  - 预期：筛选文字仍在。没有匹配时显示「没有匹配的文件」。
- [ ] 在文件树上对一个文件打开右键菜单。
  - 预期：有「添加到聊天」。点下去后，该文件进入当前会话的待发送附件，而不是直接发走。

### 对话时间线与输入框（#138 / #140 / #146）

- [ ] 发一条会调用工具的消息（例如「列出当前目录的文件」），等这一轮结束。点开「用时」那一行。
  - 预期：过程收成一行「Agent 名 · 用时 …」。展开后能看到工具步骤。最终答复留在这行下面，不进折叠。
- [ ] 发一条会写很长的消息（例如「用中文写一篇八百字的说明」）。回答还在往外长时，把滚动条拉离底部，再滚回底部。
  - 预期：离开底部后不会被硬拉回去；回到底部后继续跟随新内容。
- [ ] 用中文输入法在输入框里打拼音。候选还没上屏时按 Enter。等字上屏后，再按一次 Enter。
  - 预期：候选还在时，这一下只确认输入法，不会把半截拼音发出去。上屏后再按 Enter 才发送。
- [ ] 输入一句还没发出的草稿，连续快按两次发送。发出去之后立刻再打几个字。
  - 预期：同一次草稿只发出去一次。发送过程中再打的字不会被清掉。
- [ ] 把权限设成「询问批准」。发一条需要跑命令的消息（例如「在终端执行 dir」）。批准卡出现后，用鼠标点到输入框外面，再按 Esc。
  - 预期：批准卡在输入框上方，不折进「用时」。Esc 只拒绝当前这张卡。失败后可以再选一次。
- [ ] 发一条会同时写正文并调用工具的消息（例如「列出当前目录的文件，并说明你看到了什么」），等这一轮结束。
  - 预期：仍按会话顺序排列（用户消息、过程、答复），不会因为后到的旧事件插到前面。
- [ ] 打开支持计划模式的 Codex 会话。在输入框输入 `@`，选「计划模式」；或发送 `/plan`。
  - 预期：进入之前，输入框底部没有「计划」。进入之后页脚才出现「计划」，占位变成「描述你的任务以生成计划」。发出一条消息后「计划」仍亮着。再点一次「计划」才关掉，占位回到「随心输入」。

### 在资源管理器中打开（#142）

- [ ] 对一个有本地路径的项目打开「…」菜单。
  - 预期：有「在资源管理器中打开」。点下去后，资源管理器打开该项目目录。
- [ ] 先退出刚才的窗口。再用另一份临时数据目录启动，并放进一个没有路径的项目。不要改平时那个数据目录。PowerShell：

  ```powershell
  $env:APPDATA = Join-Path $env:TEMP "awb-accept-nopath"
  $dir = Join-Path $env:APPDATA "com.aiworkbench.app"
  New-Item -ItemType Directory -Force $dir | Out-Null
  $json = @'
  [
    {
      "id": "no-path",
      "name": "无路径",
      "path": "",
      "default_agent": "codex-cli",
      "created_at": 1,
      "updated_at": 1
    }
  ]
  '@
  $utf8 = New-Object System.Text.UTF8Encoding $false
  [System.IO.File]::WriteAllText((Join-Path $dir "projects.json"), $json.Trim(), $utf8)
  & "$env:LOCALAPPDATA\AI Workbench\AI Workbench.exe"
  ```

  对侧栏里的「无路径」打开「…」菜单。看完后关掉这个窗口。
  - 预期：没有「在资源管理器中打开」。菜单是「置顶」「编辑」，分隔线，然后是「移除项目」。

- [ ] 对两个以上项目打开「…」菜单。
  - 预期：自上而下是「置顶」「编辑」，分隔线，有本地路径时还有「在资源管理器中打开」，最后是「移除项目」。
- [ ] 点「置顶」，再对另一个项目点「置顶」。
  - 预期：侧栏出现「置顶」区。置顶项按原来的项目顺序排在该区，未置顶的留在下面的项目区。再点「取消置顶」后，该项回到项目区，置顶区没有空行。
- [ ] 关掉应用再打开。
  - 预期：置顶还在。
- [ ] 先在另一个已有目录里单独开一轮 Codex 会话，确认那个目录自己的项目下已经有这条会话。回到要编辑的项目，点「编辑」。改名称，点「添加文件夹」加上那个目录，点「保存」。
  - 预期：侧栏名称立刻更新。该项目能看到两个目录下的会话。磁盘上的文件夹没有被移动或改名。
- [ ] 编辑时把名称清空，或把另一个项目已经占用的目录设成源文件夹后保存。
  - 预期：名称空时「保存」不可用。目录冲突时提示「该目录已在项目列表中」，原项目不变。
- [ ] 在编辑框里点「移除本地项目」。
  - 预期：项目从侧栏消失，对应置顶一并去掉。磁盘目录还在。

### 计划确认面板（#148）

需要一个 Codex 会话。先进入计划模式：在输入框输入 `@`，选「计划模式」；或发送 `/plan`。页脚出现「计划」、占位变成「描述你的任务以生成计划」之后，再做下面几项。只回一句、没有写出计划时，不会出现「实施此计划？」。

- [ ] 让它写完一份计划，并等这一轮正常结束。可以发「先给出计划：只列出当前目录里的文件，不要改文件」。
  - 预期：输入框上方出现「实施此计划？」，三个选项是「是，实施此计划」「是，清空上下文并实施」「否，留在计划模式」。这张卡不折进上面的「用时」。
- [ ] 不点选项，在输入框里另写一句计划修改（不要空着）并发送。
  - 预期：这句话当作计划反馈发出去，留在计划模式。不要出现「请选择一个选项」。
- [ ] 计划再次结束后，点「否，留在计划模式」，或按 Esc（焦点不在输入框、按钮上）。
  - 预期：确认卡收起，仍是计划模式，「计划」按钮还亮着。
- [ ] 再让计划结束并出现确认卡，点「是，实施此计划」。
  - 预期：离开计划模式并开始按计划做事。底部「计划」随之关掉。
- [ ] 再进入计划模式并等到确认卡出现，然后停止这一轮；或让这一轮失败。看输入框上方。
  - 预期：不再浮出这张确认卡。

### 会话与文件模块共用预览壳（#149）

- [ ] 让 Codex 在回复里给出一个可点的项目文件。点回复中的文件链接，或点带行号的写法（例如 `docs/note.md (line 1)`）。不要从目录树或「再打开文件」打开。没有链接的普通路径文字点不开，换一句会写出文件链接的消息再试。
  - 预期：右侧是「打开文件」这一套：文件标签、标签上的「+」、面包屑、顶栏「在文件中搜索」「复制路径」「打开」、文件树按钮。不会另开一个只有正文的标签。
- [ ] 点标签上的「+」，再选一个文件。再点某个标签的关闭。
  - 预期：新文件成为当前标签。关掉当前文件后，旁边的标签接上；全部关掉后预览区回到「打开文件 / 从工作区目录树中选择文件」。
- [ ] 点「打开」。再点旁边的箭头。
  - 预期：直接「打开」用系统默认程序打开该文件。箭头菜单里有「用默认应用打开」和「选择应用…」。「选择应用…」弹出系统的打开方式。
- [ ] 点顶栏文件树按钮，把树关掉。再在会话正文里点开另一个文件链接。
  - 预期：树保持关掉。不要被这次打开强行展开。
- [ ] 用命令面板「显示/隐藏导航面板」，或浏览器新标签页里的「文件」，打开文件模块。
  - 预期：同样是上面这套顶栏和标签。这一次右侧文件树是展开的。
- [ ] 在树展开时于筛选框打字，切走再回来。
  - 预期：筛选还在。目录行只展开，文件行才换预览。
- [ ] 打开 Markdown，看顶栏。
  - 预期：「查看源代码 / 查看预览」和搜索、复制、「打开」、文件树在同一排。
