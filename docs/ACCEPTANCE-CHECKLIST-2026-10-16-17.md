# AI Workbench 0.2.64 验收清单（2026-10-16 ~ 10-17）

安装 `release/AI Workbench_0.2.64_x64-setup.exe` 后，按下面逐项勾选。每项先做步骤，再对照预期。界面以产品中文为准。

装好后窗口标题应为「AI 工作台」。

## 已在 main 上（本包仍应正常）

### 文件导航与空项目（#133 / #134）

- [ ] 打开一个有文件的项目。用命令面板「显示/隐藏导航面板」，或在浏览器新标签页点「文件」（Ctrl+P）。
  - 预期：目录只展开，不打开预览；点文件才出现预览。面包屑可下钻目录。
- [ ] 打开一份 Markdown。
  - 预期：顶栏同一排能在「查看源代码」和「查看预览」之间切换，不另开一条薄壳标签。
- [ ] 侧栏没有任何项目，也不要先开「新聊天」。
  - 预期：主区停在「选择一个项目」，不会自己落到一张空白新聊天。
- [ ] 选中一个还没有会话的项目。
  - 预期：出现可输入的草稿，侧栏不先插一条空会话。发出第一条消息后，草稿换成真正的会话。
- [ ] 项目列表为空时看侧栏。
  - 预期：提示「还没有项目。点击上方 + 创建。」

### MCP 设置（#135 / #136 / #145）

- [ ] 打开设置里的「MCP 服务器」。在 Codex 与 Claude 两个标签之间来回切。
  - 预期：列表跟当前标签走，不会把上一个 Agent 的行画到这一个上。未安装的标签有说明，不假装已有服务器。
- [ ] 看已有服务器行。
  - 预期：没有明确「已连接」时显示「已配置」。开关跟「启用 / 禁用」走。成功和失败各有自己的短提示，失败标题对得上刚才的操作。
- [ ] 点「添加服务器」。分别选 STDIO、HTTP、SSE（以当前 Agent 实际给出的类型为准）。
  - 预期：表单只出现这个传输方式该有的字段。Codex 能改启用状态；Claude 能填环境变量和启动参数。协议名保持 STDIO、HTTP、SSE。
- [ ] 把一段服务器 JSON，以及多行「键=值」，贴进添加表单。
  - 预期：只填当前界面有的字段（名称、命令、环境变量、Headers 等）。不该出现的字段不会被塞进来。某一项不合法时，错误写在该项旁边，而不是整表一句话。
- [ ] 环境变量或请求头的值里故意放一个换行后保存。
  - 预期：该项报错（环境变量值不能换行 / 请求头的值不能换行），服务器不会被存成坏配置。

### 右侧栏（#137 / #140）

- [ ] 用命令面板打开「显示/隐藏“变更”面板」或「显示/隐藏导航面板」。拖动分隔条，再收起、再打开。
  - 预期：列宽还在。收起后再开，不会把筛选字或已选文件弄丢。
- [ ] 在「打开文件」的筛选框输入几个字，切到别的标签再回来，或收起右侧栏再打开。
  - 预期：筛选文字仍在。没有匹配时显示「没有匹配的文件」。
- [ ] 在文件树上对一个文件打开右键菜单。
  - 预期：有「添加到聊天」。点下去后，该文件进入当前会话的待发送附件，而不是直接发走。

### 对话时间线与输入框（#138 / #140 / #146）

- [ ] 发一条会调用工具的消息，等这一轮结束。
  - 预期：过程收成一行「Agent 名 · 用时 …」。展开后能看到工具步骤。最终答复留在这行下面，不进折叠。
- [ ] 回答还在往外长时，把滚动条拉离底部，再滚回底部。
  - 预期：离开底部后不会被硬拉回去；回到底部后继续跟随新内容。
- [ ] 用中文输入法组字，在候选还没上屏时按 Enter。
  - 预期：这一下只确认输入法，不会把半截拼音发出去。上屏后再按 Enter 才发送。
- [ ] 连续快按两次发送。
  - 预期：同一次草稿只发出去一次。发送过程中再打的字不会被清掉。
- [ ] 在需要批准或回答问题时，看输入框上方的卡片。用 Esc（焦点不在输入框里）拒绝批准。
  - 预期：批准卡在输入框上方，不折进「用时」。Esc 只拒绝当前这张卡。失败后可以再选一次。
- [ ] 同一轮里如果工具和正文的到达顺序错开，看时间线。
  - 预期：仍按会话顺序排列（用户消息、过程、答复），不会因为后到的旧事件插到前面。
- [ ] 打开支持计划模式的会话，点底部「计划」。
  - 预期：按钮保持打开，占位变成「描述你的任务以生成计划」。发出一条消息后「计划」仍亮着。再点一次「计划」才关掉，占位回到「随心输入」。

### Agent 列表（#141）

- [ ] 看新建会话时的 Agent 菜单，以及设置里能选的 Agent。
  - 预期：只有当前机器上已安装、并且能开会话的 Agent。列表里没有 Goose、Copilot CLI、Kiro。
- [ ] 未安装的 Agent。
  - 预期：不能拿来新建会话，也不会被当成默认项。

### 在资源管理器中打开（#142）

- [ ] 对一个有本地路径的项目打开「…」菜单。
  - 预期：有「在资源管理器中打开」。点下去后，资源管理器打开该项目目录。
- [ ] 对没有本地路径的项目打开同一菜单。
  - 预期：没有「在资源管理器中打开」。

### 作曲栏分支菜单（#143）

- [ ] 打开一个 git 仓库项目的会话，看输入框上方。
  - 预期：有当前分支芯片。点开后可以搜索（占位是「搜索{项目名}分支」）、点另一条分支切换、以及「创建并检出新分支…」。
- [ ] 打开一个不是 git 仓库的项目。
  - 预期：不显示分支芯片，也不出现「当前目录不是 git 仓库」占住输入框。

## 本轮新合入

### 项目置顶与编辑（#147）

- [ ] 对两个以上项目打开「…」菜单。
  - 预期：自上而下是「置顶」「编辑」，分隔线，有本地路径时还有「在资源管理器中打开」，最后是「移除项目」。
- [ ] 点「置顶」，再对另一个项目点「置顶」。
  - 预期：侧栏出现「置顶」区。置顶项按原来的项目顺序排在该区，未置顶的留在下面的项目区。再点「取消置顶」后，该项回到项目区，置顶区没有空行。
- [ ] 关掉应用再打开。
  - 预期：置顶还在。
- [ ] 点「编辑」。改名称，点「添加文件夹」加上另一个已存在的目录，点「保存」。
  - 预期：侧栏名称立刻更新。该项目能看到两个目录下的会话。磁盘上的文件夹没有被移动或改名。
- [ ] 编辑时把名称清空，或把另一个项目已经占用的目录设成源文件夹后保存。
  - 预期：名称空时「保存」不可用。目录冲突时提示「该目录已在项目列表中」，原项目不变。
- [ ] 在编辑框里点「移除本地项目」。
  - 预期：项目从侧栏消失，对应置顶一并去掉。磁盘目录还在。

### 计划确认面板（#148）

需要一个能跑计划模式的 Codex 会话。

- [ ] 打开「计划」，让它写完一份计划并结束这一轮。
  - 预期：输入框上方出现「实施此计划？」，三个选项是「是，实施此计划」「是，清空上下文并实施」「否，留在计划模式」。这张卡不折进上面的「用时」。
- [ ] 不点选项，在输入框里另写一句计划修改（不要空着）并发送。
  - 预期：这句话当作计划反馈发出去，留在计划模式。不要出现「请选择一个选项」。
- [ ] 计划再次结束后，点「否，留在计划模式」，或按 Esc（焦点不在输入框、按钮上）。
  - 预期：确认卡收起，仍是计划模式，「计划」按钮还亮着。
- [ ] 再点「是，实施此计划」。
  - 预期：离开计划模式并开始按计划做事。底部「计划」随之关掉。
- [ ] 会话已停止或失败时，看输入框上方。
  - 预期：不再浮出这张确认卡。

### 会话与文件模块共用预览壳（#149）

- [ ] 在会话正文里点开一个项目文件。
  - 预期：右侧是「打开文件」这一套：文件标签、标签上的「+」、面包屑、顶栏「在文件中搜索」「复制路径」「打开」、文件树按钮。不会另开一个只有正文的标签。
- [ ] 点标签上的「+」，再选一个文件。再点某个标签的关闭。
  - 预期：新文件成为当前标签。关掉当前文件后，旁边的标签接上；全部关掉后预览区回到「打开文件 / 从工作区目录树中选择文件」。
- [ ] 点「打开」。再点旁边的箭头。
  - 预期：直接「打开」用系统默认程序打开该文件。箭头菜单里有「用默认应用打开」和「选择应用…」。「选择应用…」弹出系统的打开方式。
- [ ] 点顶栏文件树按钮，把树关掉。从会话里再点开另一个文件。
  - 预期：树保持关掉。不要被这次打开强行展开。
- [ ] 用命令面板「显示/隐藏导航面板」，或浏览器新标签页里的「文件」，打开文件模块。
  - 预期：同样是上面这套顶栏和标签。这一次右侧文件树是展开的。
- [ ] 在树展开时于筛选框打字，切走再回来。
  - 预期：筛选还在。目录行只展开，文件行才换预览。
- [ ] 打开 Markdown，看顶栏。
  - 预期：「查看源代码 / 查看预览」和搜索、复制、「打开」、文件树在同一排。
