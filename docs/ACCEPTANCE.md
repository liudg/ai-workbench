# 验收标准

首稿。功能合并前按本文核对。本文独立于 `AGENTS.md`，不往那里加链接，也不记每一轮做了什么。

改到哪一区，就做完第 1 节的门，再勾第 2 节里对应的清单。没改到的区不用重走。

## 1. 合并前的门

下面几项都过了才能合并。少一项就停在 PR 上，写明缺的是哪一项。

### 1.1 远程评审

PR 要有一次不由改动作者完成的审阅，看 diff 和说明，而不是只看作者本机的自测结论。审阅没过不合并。

### 1.2 类型检查和测试

在包含这次改动的树上跑：

- `pnpm exec tsc -b --pretty false`
- `pnpm test`
- `cargo test --manifest-path src-tauri/Cargo.toml`

三条都要有结果。失败不能合并。某条与这次改动无关、因而没跑时，在 PR 里写明没跑哪一条。

### 1.3 Windows 真机

安装包在 Windows 上构建（`.github/workflows/release-windows.yml`，或本机 Windows）。Linux 上的 `tsc` / `cargo test` 不能代替真机。

改了用户看得见的路径时，用这次的 Windows 构建把这条路径走完：主路径、空状态、失败状态，以及和它读同一份状态的相邻界面。只看一张截图不算通过。

### 1.4 界面文案

用户看得见的字符串用产品中文。

可以保留英文的只有协议名和产品专名：MCP、STDIO、HTTP、SSE、OAuth、JSON、URL、Headers、Bearer，以及 CLI 产品名、模型 id、用户自己的路径和命令。

不把实现说明、对照笔记、研究过程写进界面。MCP 的 `notes` 只留在代码里给测试，设置页不渲染。界面上不出现「未观察」「未验证」「动词」。

文案集中在 `src/shared/strings/desktop-zh.ts` 和各功能自己的文案常量（例如 `src/features/workspace/settings/mcp/view.ts`）。新增句子先放进这类常量，不在组件里散落英文标题。

### 1.5 对齐 Codex

有官方 app-server 或 TUI 对应物的功能，跟官方逻辑和已有 API 走，不另写一套协议。

对不上官方安装包的部分标「未观察」，不实现。界面用当前会话的能力和数据决定能做什么，不用 Agent 名字分支。

模型、强度、权限、服务档位只来自当前适配器或它的 CLI，不把另一个 Agent 的目录拿来显示或写入。

能力开关只有在该 Agent 原生确实不支持时才关。关掉的项在代码注释里写明证据（命令、帮助文字，或会话文件里确实没有）。支持的项要有实现，不用空返回冒充已接通。

### 1.6 改 Agent 配置时先备份

会写入 Agent 自己的配置（例如 Codex 的 `config.toml`）时：

1. 改之前复制原文做备份。
2. 新内容先写临时文件，再替换目标。Codex MCP 现有写法是目标路径加 `.wb-tmp`，见 `src-tauri/src/features/agents/codex/mcp.rs` 的 `write_config`。
3. 替换前能把新内容读回来，并且读到的就是这次要写的值。读不回来就不替换。
4. 替换失败，或读回校验失败：恢复备份，删掉临时文件。
5. 成功后删掉临时文件。符号链接写解析后的目标，链接本身留着。
6. 原文是 CRLF 的，写回仍是 CRLF。

不在校验通过前让用户的配置停在半截。

### 1.7 清掉临时文件

临时目录带这次任务的名字，用完删除。不往公共临时目录写通用文件名。

测试里创建的目录在结束时删掉。配置写入用的 `.wb-tmp` 不能留在用户目录里。MCP 和管理命令的工作目录用临时目录，不拿用户项目当工作目录去跑会改项目状态的子命令。

### 1.8 发布只留最新安装包

`pnpm tauri:build` 之后由 `scripts/copy-installer.mjs` 把当前版本复制到 `release/`：

- 只保留这一版的 `*_x64-setup.exe` 和同名 `.sig`。
- 该目录里其它版本的安装包（含旧的 `.nsis.zip`）删掉。
- `release/latest.json` 和 `release/README.md` 保留。
- 安装包不入库。

## 2. 分区清单

勾选表示在这次改动涉及的构建上亲眼看过。没改到的分区标「未改」。

### 2.1 聊天区

代码在 `src/features/chat/timeline/`、`src/features/chat/events/`、`src/features/chat/cards/`。

- 空会话有空状态，不出现空白崩溃。
- 用户消息、助手回复、思考、工具行按时间线出现；回合进行中持续往下长，不整段等到结束才出现。
- 工具输出、补丁正文默认折叠；回合结束后，进行中点开的活动收起。
- 提问卡、审批卡可以回答；答完卡片收成结果，不残留可点的旧按钮。
- 有文件变更且当前 Agent 声明了变更能力时，才出现变更卡和「查看变更」。
- 继续会话能看到已有回合；声明了分页历史的 Agent，上滚会再要更早的回合，而不是一次截断后假装没有了。
- 会话被其它进程占用时，时间线仍可看，发送被拒绝，并有中文说明。
- 换 Agent 后，时间线不拿上一个 Agent 的目录或能力来画这一条。

### 2.2 作曲栏

代码在 `src/features/chat/composer/`。

- 发送、停止当前回合可用；停止不结束会话，也不清空队列。
- 回合进行中再发送：声明了队列的 Agent 进入排队；可以改、删、引导。没声明队列的不显示排队。
- 计划、目标、审查、图片、技能、斜杠只在当前能力为开时出现。关着的项不显示入口，也不借用另一个 Agent 的命令。
- 模型、强度、服务档位来自当前会话目录。目录还没读到时显示「正在读取」一类状态，不用别的 Agent 的上次选择。
- 权限菜单来自当前适配器。档位标题是中文；说明性 `description` 不进菜单，只保留不可选原因。
- 网络开关和额外目录只在菜单声明允许时出现。
- 切换会话后，各自未发送的草稿还在，包括附件。
- 第一条消息发送失败时，输入回到作曲栏，会话仍可选中。

### 2.3 右侧栏

标签和查看器在 `src/features/panel/`。浏览器、变更、文件预览是不同的查看器，共用标签栏。

- 可以新开、切换、关闭标签。关闭当前标签后，相邻标签接上，不留空面板。
- 完整视图与退出完整视图不丢当前标签和会话标题。

浏览器（`src/features/panel/browser/`）：

- 地址栏可以打开、后退、前进、重新加载。打不开时有中文错误，不白屏。
- 新标签页、批注入口在。批注失败仍可用中文说明，不把异常原文铺满页面。

查看变更（`src/features/panel/diff/`，文案「查看变更」）：

- 范围来自当前适配器：上一轮，以及未提交 / 未暂存 / 已暂存。没有回合 diff 的 Agent 不显示「上一轮」。
- 不是 git 仓库时显示「当前目录不是 git 仓库」，不编造差异。
- 文件列表可筛选；选中文件后差异区跟着变。隐藏文件、换行、词级差异、复制 git apply 各自生效。

文件树和预览要分成两层，不要混在一次点击里：

- 导航层：工作区树（`WorkspaceTree`）和面包屑下拉（`BreadcrumbMenu`）。目录只展开，不打开预览。文件才产生预览意图（`src/features/panel/files/file-preview-nav.ts`）。
- 内容层：选中文件之后的预览（`PreviewBody` / `FilePreview`）。空、加载中、失败、过大、不支持的类型各自有壳。Markdown 的「查看源代码 / 查看预览」在内容层里面，不放进导航层。
- 顶栏（`PreviewChrome`）只放路径、复制、搜索、文件树显隐，不把查看器嵌进顶栏。

### 2.4 MCP 设置

代码在 `src/features/workspace/settings/mcp/`，能力在 `src-tauri/src/features/agents/mcp/surface.rs`。

- 设置页一种已注册 Agent 一份。按钮只跟这份 surface 的动词和规则走，不按 Agent 名字写死。
- 未安装：说明安装后可以管理。已安装但还没验证：说明暂不能在此管理。两句都是产品中文，不写「未验证」「动词」。
- `notes` 不出现在页面上。
- 列表、添加、卸载、启用、禁用、身份验证、取消认证、查看工具，只在对应动词为真时出现。
- 添加表单的字段跟 `fields` 和传输类型走。帮助里没有的旗标不做成输入框。
- 会改配置文件的操作遵守第 1.6 节。失败时配置回到改之前，页面上有中文错误。

### 2.5 本地 Agent 页

代码在 `src/features/workspace/settings/SettingsView.tsx`、`agent-card.ts`。探测范围是 `AgentKind::all`（`src-tauri/src/models/agent.rs`）。

- 列出的是已注册的七种：Codex CLI、Claude Code、Cursor Agent、Kimi Code、Qwen Code、OpenCode、Antigravity。Goose、GitHub Copilot CLI、Kiro CLI 不出现。
- 未安装、已安装未接入、已接入，三种卡片分得开。未接入写「未接入」，不附一段协议说明。
- 工作台不代为安装。已安装且官方渠道报告可更新时才有「更新」。更新中按钮不可连点。
- 更新失败有中文错误，卡片仍留着原来的版本。
- 「重新检测」会刷新列表，不把上一次的错误留在已经成功的卡片上。
- 新建会话只提供已接入、本机找得到的种类。

### 2.6 会话和项目

项目命令在 `src-tauri/src/features/ipc/projects.rs`，会话在 `src-tauri/src/features/sessions/manager.rs`，侧栏菜单在 `src/features/sidebar/sessions/session-menu.ts`。

- 新建项目、导入已有目录写入工作台自己的项目列表，不改 Agent 的会话存储。
- 同一路径不能重复加入。
- 从列表移除项目会先停掉该项目下已打开的会话，不删磁盘目录，也不删 Agent 侧的会话记录。来自 Agent 会话目录、不在工作台列表里的项不能单独移除。
- 侧栏会话菜单只看当前能力：重命名、归档、删除各自开关。置顶是工作台本地状态，始终在。菜单里没有分叉，即使适配器实现了 `fork_thread`。
- 未声明归档的 Agent 不出现归档。归档后的会话不进默认列表，取消归档后回来。
- 删除前有确认。删除的是任务，不是工作区文件。不支持删除的 Agent 不出现删除。
- 还没发出第一条消息就放弃的会话，由适配器撤掉刚建的线程，侧栏里不留空会话。
- 换项目或换会话后，作曲栏目录、权限和右侧预览跟当前会话走，不残留上一个的模型或文件。
