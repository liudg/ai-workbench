# 文件搜索和选区

## 索引

侧栏筛选、`@` 提及和「在文件中搜索」共用一份内存路径索引。索引不落盘，也不走 Agent 自己的文件搜索。

- 文件名筛选和 `@` 提及只匹配相对路径，不打开文件。内容搜索是另一条通道：按掩码读正文，跳过二进制和超过 1MB 的文件，旧的 `searchId` 会取消还没读完的内容。
- 打开项目后开始后台扫描。查询先返回已经扫到的匹配，`ready` / `done` 在整棵树扫完后才为真。`@` 提及在 `ready` 之前保持等待，不把半段结果当成最终结果。
- 扫描遵守 `.gitignore`、嵌套 `.gitignore`、`.git/info/exclude` 和全局排除。`.git`、`node_modules`、`target`、`dist`、`Library`、`Temp` 仍然跳过，即使 gitignore 把它们加回来。
- 大约每 2 秒核对目录修改时间。只有变化的那一层会重读。正文不缓存，内容搜索每次读当前文件。
- 索引还没建完时筛选结果带 `ready: false`，界面接着要下一段，并保留已经找到的文件。

## 选区

打开的文件可以拖选和复制。选中文字后只出现「添加到对话」，没有「编辑」。菜单出现在松开鼠标的位置；贴着窗口边缘时收进屏幕里。聊天记录里的选区用同一菜单，没有文件路径，发送时是引用块。

点击后把选区收成当前会话的文本片，不写进输入框。作曲栏出现「N 个已选文本片」，上方是片段预览。发送时再把围栏拼进消息，例如：

````
```12:15:/abs/File.cs
选中的文本
```
````

文本片记在会话上。不会假装已经发给模型。
