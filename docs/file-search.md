# 文件搜索和选区

## 索引

侧栏筛选框和「在文件中搜索」共用一份工作区索引。

- 文件名筛选匹配相对路径，大小写不敏感，跳过 `.git`、`node_modules`、`target`、`dist`、`Library`、`Temp`。
- 内容搜索仍是文件名命中加行命中，掩码、二进制和 1MB 上限跟原来一样。
- 目录只在第一次读取。之后的查询走内存里的路径和已经读过的正文。
- 大约每 2 秒核对目录修改时间。只有变化的那一层会重读。文件内容变化看文件自己的修改时间或长度，作废那一份缓存，不把整棵树再扫一遍。
- 索引还没建完时筛选结果带 `ready: false`，界面接着要下一段，并保留已经找到的文件。

## 选区

打开的文件可以拖选和复制。选中文字后只出现「添加到对话」，没有「编辑」。菜单默认在选区上方；贴着窗口上沿时改到选区下方，避免被裁掉。

点击后把路径和选中正文写进当前会话的作曲栏，形如：

```
```12:15:/abs/File.cs
选中的文本
```
```

作曲栏还没挂上时先留着，挂上后补进输入框。不会假装已经发给模型。
